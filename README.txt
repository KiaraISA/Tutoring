KeyStone Tutors - Streamlit site
================================

START THE SITE
Double-click "Start KeyStone Site". Your browser opens it at localhost:8600.
Close the black window when you're done.

ADMIN TAB
Password: see .streamlit/secrets.toml (open it with Notepad to change it).
In Admin you can:
  - Packages:     track each package (lesson 2 of 4, paid / not paid). It shows
                  who's finished and how much each tutor is owed (51%).
  - Bookings:     every "Book a lesson" form a parent sends.
  - Applications: every "Join our team" form.
  - Tutors:       edit the "Our tutors" page (fill in Palesa's details!).
  - Reviews:      paste real parent messages; ticked ones show on Home.
Click the Save button under a table after editing it.

YOUR DATA
Everything is saved in the "data" folder as CSV files (opens in Excel).
Back that folder up - it's your records.

EDITING PRICES / CONTACT DETAILS
They're in the block at the top of app.py.
